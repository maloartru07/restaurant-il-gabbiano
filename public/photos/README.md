# Dossier photos

Placez ici les vraies photos du restaurant, avec ces noms de fichiers pour qu'elles soient utilisées automatiquement :

- `pizza.jpg` — une pizza
- `pates.jpg` — un plat de pâtes
- `salade.jpg` — une salade (paysanne ou campagnarde)
- `tiramisu.jpg` — le tiramisu ou un dessert maison

Tant qu'un fichier n'existe pas, le site affiche un fond de couleur élégant à la place (voir `src/components/PhotoSlot.astro`). Aucune image n'est inventée ni récupérée depuis Tripadvisor, Google ou Instagram.

Format recommandé : `.jpg` ou `.webp`, environ 1600×1200 px, poids inférieur à 400 Ko pour garder le site rapide.
